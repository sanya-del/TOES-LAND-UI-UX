# TOES LAND – UI/UX Design

A UI/UX design project for a **children’s fashion shopping app**, created in Figma with a focus on simple navigation, attractive visuals, and a user-friendly shopping experience.

## 🎨 Design Tool
- Figma

## 📱 Project Features
- Children’s clothing collections
- Product browsing and product details
- Search and category navigation
- Offers and wishlist
- Shopping cart and checkout flow
- User profile and settings

## 🖼️ Design Process

### Medium-Fidelity
Wireframes and layout designs focusing on screen structure and user flow.

### High-Fidelity
Final visual designs with colours, typography, images, buttons, and UI elements.
